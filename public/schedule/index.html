v7.0 — Smart Roster Intelligence & UX Overhaul Latest

August 13, 2026

  • AM/PM Time Format: All shift times now display in friendly 12-hour format (e.g. 8:15 AM - 5:30 PM) across Dashboard, Daily View, and tables.
  • Coverage Gap Warnings: Daily View auto-detects and alerts when staff coverage drops to 1 person or no Pharmacist is rostered in a time slot.
  • Dashboard Coverage Banner: Today's Schedule shows a summary bar with total staff, pharmacist count, and coverage window at a glance.
  • Weekly Headcount Row: Scheduler grid footer now displays per-day staff headcount badges for quick resource planning.
  • OT Alert Badges: Employee profiles show ⚠️ OT warning when weekly hours exceed 38h (full-time threshold).
  • Shift Conflict Guard: Leave requests now block submission when scheduled shifts exist on the requested dates.
  • A4 Print Upgrade: Daily View prints with clean A4 landscape layout, Amcal header, proper ink-safe styling, and footer URL.
v6.10 — Timeline Bar Break Badges in Daily View

August 13, 2026

  • Timeline Bar Break Badges: Rendered 30m Lunch & Paid Rest Break badges directly on top visual timeline bars in Daily View alongside staff names and roster roles.
v6.9 — Pharmacy Award 2026 & Amcal Woy Woy Roster Standard

August 13, 2026

  • Pharmacy Award 2026 Standard: Updated all break compliance algorithms, shift modals, manuals, and PDF documentation to reference the operative Pharmacy Industry Award 2026 [MA000084].
  • Official App Branding: Standardized application naming exclusively to Amcal Woy Woy Roster across all interfaces and documentation.
v6.8 — Breaks Integrated in Daily View

August 13, 2026

  • Daily View Breaks Column: Added dedicated "Breaks (Award)" column in the Daily View schedule table, displaying 30m Unpaid Lunch & Paid Rest Break badges for each staff member's shift.
  • Timeline Tooltips: Integrated break entitlements directly into the interactive daily timeline visual bar tooltips.
v6.7 — 1-Click Weekly Roster Replication

August 13, 2026

  • 1-Click Copy Week: Duplicate the entire current week's roster (staff assignments, hours, positions, breaks, notes) to the following week with a single click.
  • Auto Navigation: Automatically navigates to next week's view with instant Supabase database persistence.
v6.5 — Pharmacy Award Breaks & UI Layout Optimization

August 13, 2026

  • Pharmacy Award MA000084 Breaks: Integrated 30-minute unpaid lunch break and 10-minute paid rest breaks (1x for shifts 4–7.5h, 2x for full shifts 7.6h+).
  • Shift Modal Layout Fix: Refactored break compliance box and net paid hours layout to eliminate horizontal modal overflow on all screen sizes.
  • Timeclock Terminal: Added dedicated "30m Lunch (Unpaid)" and "10m Rest (Paid)" break buttons with real-time status indicators.
v6.3 — Custom Staff Reordering & A4 Roster Printing

August 12, 2026

  • Staff Reordering: Added interactive Move Up / Move Down controls (▲/▼) in the Scheduler grid and Employees directory to customize staff row order with persistent database saving.
  • A4 Landscape Roster Print: Built `@media print` CSS optimization for A4 Landscape size fit. Hides non-printable UI and fits 7-day weekly rosters seamlessly.
v6.2 — Timecard Hours Calculation & Serverless Payload Guards

August 09, 2026

  • Timecard Math Resilience: Fixed dashboard Worked Hours 0.0h bug by supporting ISO date string parsing and overnight midnight crossings.
  • Serverless Security: Added strict payload string type guards (`typeof string`) to authentication endpoints.
  • Timezone Handling: Improved `getMondayOfCurrentWeek` to parse local date strings without UTC day shifting.
v5.0 — Native Supabase Auth & Node 22 LTS

August 09, 2026

  • Implicit Auth Flow: Switched to Supabase Auth implicit flow for instant 0ms password reset links without expired code errors.
  • Node 22 LTS Engine: Configured Vercel deployment engine to Node.js 22 LTS standard.
